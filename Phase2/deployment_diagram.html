1 · Compute & Access — Azure App Service · Static Web Apps · Container Apps (VNet app-subnet 10.1.0.0/24)
Azure Front Door + WAF
[Node: Azure PaaS — public ingress]

Azure Static Web Apps
[Node: Azure PaaS]
Deploys [Container: Frontend — React SPA]
upload UI, audit view, NL query, templates
Azure App Service (Linux)
[Node: Azure PaaS]
Deploys [Container: Backend API — Python FastAPI]
REST API, Entra ID JWT validation, RBAC
Azure Container Apps Environment
[Node: Azure PaaS — K8s-backed, autoscaling]
Ingestion & Processing Service [Celery workers] connector crawl (SharePoint, Confluence, servers, DBs) + ETL: extract → chunk → embed → index
AI Service [Python] intent routing, RAG over unified index, audit & answer generation
Expert Directory Service [Python] subject-matter-expert matching from metadata + org profiles
2 · Data & Governance — private endpoints in VNet (data-subnet 10.1.1.0/24)

[Node: Azure PaaS — zone redundant]

• Application DB (users, audits, results, templates)
• Feedback & Learning Store (Q&A corrections)
• Governance & Audit Log

[Node: Azure PaaS]
Message broker for Celery + embedding/query cache
Azure Blob Storage
[Node: Azure PaaS]

Azure AI Search
[Node: Azure PaaS]
Unified vector index — audit docs + multi-source knowledge
Azure Key Vault
[Node: Azure PaaS]

Azure Monitor / App Insights
[Node: Azure PaaS]
APM telemetry, logs, metrics & budget alerts (80/90/100%)
3 · External Azure Services — managed by Microsoft, consumed over private endpoints

[Software System: Azure]

Azure OpenAI Service
[Software System: Azure]
LLM for answers, summaries, and AI audit results
Azure Entra ID
[Software System: Azure]
OAuth2/OIDC identity provider + role assignments (Vendor / Customer)
4 · Corporate Network — on-premises systems (accessed over VPN / private peering)
Enterprise Content Sources
[Node: On-premises]
SharePoint, Confluence, file servers, and internal databases — corporate knowledge & structured data
HR / Org Directory
[Node: On-premises]
Employee profiles used for subject-matter-expert identification
Operational posture (NFR): NFR-1 streaming (SSE) + Redis cache, precomputed summaries; NFR-2 queue-depth autoscaling & staged pipelines for 500 submissions/hour and 50 concurrent queries; NFR-3 99.9% availability (zone-redundant PaaS, idempotent Celery tasks, DLQ, RTO < 30 min, RPO < 15 min); NFR-4 TLS in transit, sensitive fields encrypted at rest, secrets in Key Vault via managed identities, private endpoints — no public exposure of Blob / AI Search / OpenAI / PostgreSQL.
